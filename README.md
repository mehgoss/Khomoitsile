# Khumoitsile Consulting

Khumoitsile Consulting is a digital marketing, sales, and promotions website.

* Digital marketing services
* Sales and promotions management
* Customizable website design
## Tech Stack
* HTML
* CSS
* JavaScript

1. Clone the repository: `git clone https://github.com/Khumoitsile/Khumoitsile.git`
2. Open the project in a code editor
## Usage
1. Open `index.html` in a web browser
